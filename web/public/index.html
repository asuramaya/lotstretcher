No stock backgrounds

The backdrop comes from the car.

Each backdrop is generated from that vehicle's own paint and interior colours. No two listings share one, so a feed never looks stamped out.

No API key. No asset library. No network call.

Window sticker

Specs, without typing them.

Point it at a window sticker PDF and it reads the trim, engine, colours and options straight off the page.

  • VIN, trim and drivetrain
  • Factory colour names, which set the backdrop
  • Optional equipment, into the post copy
Library

Everything it made, in one place.

The pipeline writes one folder per vehicle. The Library pane reads that folder and shows every hero, framed set, clip and post, searchable by title, VIN or stock number.

  • Open a listings folder from disk, on any browser
  • Load a vehicle's originals back in and rerun it with today's options
  • On your server: rebuild in place, re-scrape from the listing, sync the lot, delist

Nothing leaves the device.

Not encrypted in transit. Not deleted after 30 days. There is no server to send photos to. This site is static files, and the work happens in your tab.
