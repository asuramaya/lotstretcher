Import from a listing

This host can read the page for you. Paste a vehicle page address and your server fetches it, exactly as the command line does.

Or, from any browser:

Your server can scrape a vehicle page for you. A browser cannot read another site's page, so here the hand-off runs the other way: a bookmarklet on the listing itself collects the vehicle record and photo links and opens this app with them filled in.

Drag this to your bookmarks bar, then click it while viewing a vehicle page. Nothing is sent anywhere: the page's own data is handed to this app inside the link, which stays on this device.

Send to lotstretcher On a phone: copy it and paste as a bookmark's address.

Works on DealerInspire pages, the same platform the command line scraper reads. Other platforms fall back to the page's schema.org data, which is thinner. Photo links are fetched to this device by the app; a CDN that refuses cross-origin reads will say so.

Window sticker URL

A direct link to the sticker PDF. It is fetched straight to this device and parsed here. Ford's sticker host allows this; some others refuse cross-origin reads, and the app will say so.

About

lotstretcher turns vehicle photos into post-ready images and copy. Background removal, classification and compositing all run in this browser tab, on this device.

What leaves this device

Your photos: nothing. There is no account, no upload, and no server-side storage, because the site is static files. The only network requests are the one-time model download and any image URLs you paste.
