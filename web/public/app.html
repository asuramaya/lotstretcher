The simplest way, from any browser: on the listing page press Ctrl+S (Cmd+S on a Mac), save it as "Webpage, HTML only", then drop that file here. The page's own vehicle data and photo links are read on this device; nothing is fetched from the dealer.

Or a bookmarklet. A browser cannot read another site's page, and neither can lotstretcher.org: dealer sites sit behind a bot challenge that only a real browser passes (a plain fetch of a listing gets "Just a moment", not the page), which is why the self-hosted server drives one. So the hand-off runs the other way: a bookmarklet clicked on the listing itself collects the vehicle record and photo links and opens this app with them filled in.

Drag this to your bookmarks bar, then click it while viewing a vehicle page. Nothing is sent anywhere: the page's own data is handed to this app inside the link, which stays on this device.

Window sticker URL

A direct link to the sticker PDF. It is fetched straight to this device and parsed here. Ford's sticker host allows this; some others refuse cross-origin reads, and the app will say so.

About

lotstretcher turns vehicle photos into post-ready images and copy. Background removal, classification and compositing all run in this browser tab, on this device.

What leaves this device

Your photos: nothing. There is no account, no upload, and no server-side storage, because the site is static files. The only network requests are the one-time model download and any image URLs you paste.
